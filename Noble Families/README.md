# 山河帝脉 · 全球帝王贵族时间线地图

暗色交互地图，四视图：

1. **时间地图** — 拖动年份，只显示当时仍在台上的帝王 / 王朝 / 贵族世家
2. **3D 地球** — globe.gl 夜景地球，点位与飞线
3. **联姻专题** — 哈布斯堡婚约、满蒙联姻、维多利亚的孙辈
4. **世系** — 可展开主干（爱新觉罗、科尔沁、哈布斯堡、维多利亚、罗曼诺夫等 12 家）

## 打开

需要能访问 unpkg（Leaflet、globe.gl、地球纹理）和 CARTO 暗色底图。

```bash
python3 -m http.server 8765
# http://localhost:8765
```

也可直接用浏览器打开 `index.html`。

## 文件

- `index.html` 界面
- `data.js` 约 63 个世家（含科尔沁、霍亨索伦、丹麦奥尔登堡）
- `stories.js` 三场联姻专题飞线
- `trees.js` 可展开世系
- `app.js` 地图 / 地球 / 专题 / 世系逻辑

年份与谱系均为可视化约数，不是学术年表。
